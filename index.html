Presets and storage

Presets reset the part values on this page, then apply the preset. Nothing is sent until you press Send all values. The FX are shared by all parts, so they are only sent if you tick the box.

Recall discards unsaved edits. Store has no undo, and the manual doesn't say which slot CC 62 writes to, so check the module's display first. Another editor reports that CC 62 only arms the store on some units: if the preset reverts after a power cycle, press Store twice on the panel.

Whole preset (SysEx)

Sends every value as one message, VCA envelope included, instead of a burst of CCs. It starts from a real dump of your module, so the settings this page doesn't know about stay as your unit has them. Fetch one first: on the module go to Midi, Setup 3, and turn 1Prs.

Sending writes to the module's working memory for that slot. Press Store (or tick the box) to keep it, otherwise a power cycle wipes it. The module's own docs say big transfers can corrupt it, so this only ever sends one 283-byte preset. FM 1>3 has no place in the dump, so it goes out as a CC afterwards.
